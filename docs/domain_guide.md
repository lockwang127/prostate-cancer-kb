# 前列腺癌知识库 - 领域指南

## 知识库概述

本知识库采用知识三元组（Head-Relation-Tail）结构，系统化组织前列腺癌领域的医学知识，涵盖流行病学、生物标志物、分期评估、CSCO 2024指南推荐和治疗方案等核心领域。

## 知识域划分

### 1. 流行病学 (epidemiology)
- **覆盖内容**: 中国及全球前列腺癌发病率、死亡率、病死比、发病趋势、高危因素
- **数据来源**: GLOBOCAN 2022、国家癌症中心
- **关键指标**: 新发病例数、死亡人数、5年生存率、发病率排名

### 2. 病理评估 (pathology)
- **覆盖内容**: Gleason评分系统、ISUP分级
- **数据来源**: ISUP 2014共识、AJCC第8版
- **关键指标**: Gleason评分(6-10)、ISUP 1-5级

### 3. 筛查诊断 (screening_diagnosis)
- **覆盖内容**: PSA筛查、PSAD、free PSA比值、前列腺穿刺活检、mpMRI
- **数据来源**: 中国前列腺癌筛查指南、PI-RADS v2.1
- **关键指标**: PSA阈值、PI-RADS评分、穿刺方案

### 4. 分期系统 (staging)
- **覆盖内容**: TNM分期、危险分层
- **数据来源**: AJCC第8版、NCCN/CSCO指南
- **关键指标**: T分期(T1-T4)、危险分层(低/中/高危)

### 5. 治疗指南 (treatment_guideline)
- **覆盖内容**: CSCO 2024指南中不同分期的推荐治疗方案
- **数据来源**: CSCO前列腺癌诊疗指南2024版
- **关键内容**: 低/中/高危、局部晚期、mCRPC治疗策略

### 6. 药物治疗 (pharmacotherapy)
- **覆盖内容**: ADT、新型内分泌药物(NHA)、化疗、靶向治疗、免疫治疗
- **数据来源**: 药物说明书、CSCO/NCCN指南
- **关键药物**: 阿比特龙、恩扎卢胺、阿帕他胺、达罗他胺、多西他赛

### 7. 手术治疗 (surgery)
- **覆盖内容**: 根治性前列腺切除术适应证、术式、并发症
- **数据来源**: 中国前列腺癌诊疗指南

### 8. 放射治疗 (radiotherapy)
- **覆盖内容**: 外照射放疗(EBRT)、近距离放疗
- **数据来源**: 中国前列腺癌诊疗指南

### 9. 内分泌治疗 (endocrine_therapy)
- **覆盖内容**: ADT治疗方式、不良反应
- **数据来源**: CSCO指南

### 10. 化学治疗 (chemotherapy)
- **覆盖内容**: 多西他赛、卡巴他赛方案
- **数据来源**: NCCN/CSCO指南

### 11. 靶向治疗 (targeted_therapy)
- **覆盖内容**: PARP抑制剂
- **数据来源**: CSCO/NCCN指南

### 12. 免疫治疗 (immunotherapy)
- **覆盖内容**: Sipuleucel-T等
- **数据来源**: FDA批准文献

## 三元组质量标准

1. **置信度等级**:
   - 0.95-0.99: 权威指南/大型临床试验/系统综述
   - 0.90-0.94: 临床研究/多中心数据
   - 0.85-0.89: 专家共识/观察性研究
   - <0.85: 个案报告/体外研究（一般不收录）

2. **必填字段**: head, relation, tail, source, evidence, domain, confidence
3. **可选字段**: pmid (PubMed文献ID)
4. **每文件最低三元组数**: 10条

## 数据更新策略

- 指南更新: CSCO指南每年更新一次，需及时同步
- 流行病学数据: 每年更新国家癌症中心最新统计
- 新药审批: 新药获批后30天内补充
- 临床试验: Phase III结果发布后及时纳入
